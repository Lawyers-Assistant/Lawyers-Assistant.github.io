Install guide

Up and running in under five minutes.

No terminal commands. No manual installs. The launcher handles everything — Python, dependencies, AI models, and Ollama — so you can focus on your documents.

Step by step

Six steps. That's it.

01

Download the app

Click the Download the app button above (or the one at the bottom of this page). You'll get a single archive file with everything inside.

02

Extract the archive

Windows: right-click the file → Extract All…. macOS: double-click it. Move the extracted folder somewhere permanent, like Documents.

03

Run the launcher

Windows: double-click launch.bat. macOS / Linux: run launch.sh. A setup page opens in your browser — that's your control center.

Read the launcher guide →

04

Let it install everything

Click Install. The launcher sets up the Python environment, installs dependencies, downloads the AI models, and installs Ollama — automatically, with progress shown for every step.

What the launcher installs, in detail →

05

Launch the app

Once installation finishes, click Launch. The desktop app opens — usually in under a minute. From then on you can close the launcher anytime.

06

Ask your first question

Pick a folder of documents, click Ingest all files, then type a question in plain English. You'll get an answer with inline citations pointing to the exact passages.

See the quickstart guide →

One download, three platforms

Works on your computer.

The same archive contains everything for Windows, macOS, and Linux — run the launcher script for your system and you're done.

Windows

Double-click launch.bat after extracting. Windows SmartScreen may ask you to confirm — click More info → Run anyway.

macOS

Double-click launch.sh (or run it from Terminal). If Gatekeeper warns, right-click → Open to allow it once.

Linux

Run launch.sh from a terminal. Ensure Python 3.11+ is installed; the launcher handles the rest.

Common questions

Install questions, answered.

Do I need to install Python, Node.js, or any technical tools?

No. The launcher does everything for you: it sets up the Python environment, installs all dependencies, downloads the AI models, and installs Ollama automatically. You only need to download the app and run the launcher.

Do I need a GPU or a powerful computer?

No. Lawyer Assistant runs on any modern computer, even without a GPU. If you do have an NVIDIA GPU with enough memory, the app automatically uses it to make searching faster.

Do I need an internet connection to use it?

You need internet for the first install to download the models. After that, the app works fully offline with a local model.

Does installation cost anything?

No. Lawyer Assistant is free and open source under the MIT license. There are no subscriptions and no hidden fees.

What if the launcher fails partway through?

Each setup step can be retried on its own. Just click Retry on the failed step — you never need to restart the whole installation.
